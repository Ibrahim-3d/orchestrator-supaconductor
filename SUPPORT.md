# Support

## Questions and troubleshooting

Use [GitHub Discussions](https://github.com/Ibrahim-3d/orchestrator-supaconductor/discussions) for installation help, usage questions, configuration advice, and general troubleshooting.

When asking for help, include:

- SupaConductor version
- Claude Code version
- operating system
- installation method
- command you ran
- relevant error output
- the smallest reproducible example you can provide

## Bugs

Use the repository's bug report form for reproducible defects. Issues are for actionable bugs, not general support conversations or open-ended feature brainstorming.

## Feature ideas

Use [GitHub Discussions](https://github.com/Ibrahim-3d/orchestrator-supaconductor/discussions) so ideas can be discussed before they become implementation issues.

## Security

Do not report vulnerabilities publicly. Follow [SECURITY.md](SECURITY.md).
